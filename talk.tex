                      element method, \emph{Numer. Math.}}

            \item Handle Stokes\footnote{Wichrowski (2026), Towards matrix-free patch smoothers for the Stokes problem,
                      arXiv:2601.13230.}, CutFEM\footnote{Wichrowski (2026), A multigrid method for CutFEM and its convergence,

\begin{frame}{The classical answer: fast diagonalization}
    For a \alert{separable} operator on a \alert{Cartesian} patch\footnote{Lynch, Rice, and Thomas (1964).}:
    \begin{gather*}
        A_j = L_x \otimes M_y + M_x \otimes L_y
        \qquad\Longrightarrow\qquad
        A_j^{-1} = (Q_x \otimes Q_y)\, \Lambda^{-1} (Q_x \otimes Q_y)^T
    \end{gather*}
    with 1D eigendecompositions $L Q = M Q \Lambda$.
    \begin{itemize}
        \item Exact inverse, applied with tensor contractions: $\mathcal O(p^{d+1})$
        \item The workhorse of state-of-the-art patch smoothers\footnote{Witte, Arndt, and Kanschat (2021).}
    \end{itemize}
    \vfill
    \pause
    \begin{alertblock}{But\dots}
        \begin{itemize}
            \item Requires separability: Cartesian cells, constant coefficients
            \item Deteriorates on deformed grids, breaks on unstructured patches
        \end{itemize}
    \end{alertblock}
    \vfill
    \centering
    % So what do we do on a \emph{general} patch?
\end{frame}

\begin{frame}{The box we are already in: multigrid}
    How was multigrid invented in the first place?
    \begin{enumerate}
        \item Jacobi/Gauss--Seidel kill high frequencies, stall on low ones
        \item Fix: correct the low frequencies on a coarser grid
        \item Two-level method
        \item \emph{``And how do we solve the coarse problem?''} \quad
              \alert{Add another level.}
    \end{enumerate}
    \pause
    \vfill
    \begin{block}{The local patch problem is \emph{the same question}}
        \emph{``How do we solve the local problem?''} \pause\quad \alert{Add more levels!}
        \pause
        \begin{itemize}
            \item Solve each patch problem with its own multigrid
            \item h-coarsening not feasible: a patch is only $2^d$ cells
            \item coarsen in the polynomial degree: \alert{p-multigrid}
        \end{itemize}
    \end{block}
    \vfill
    \centering \emph{Multigrid-within-multigrid:} stay matrix-free, iterative, and lean --- all the way down.
\end{frame}

\begin{frame}{The local p-multigrid solver}
    \begin{columns}[T]
        \begin{column}{0.55\textwidth}
            \textbf{Hierarchy on the patch}\footnote{Wichrowski (2025), Local patch solvers via p-MG.} (mesh fixed):
            \begin{gather*}
                V_{j,1} \subset V_{j,3} \subset V_{j,7} \subset \dots \subset V_{j,p}
            \end{gather*}
            nested degrees $p_{k+1} = 2p_k + 1$
            \begin{itemize}
                \item Transfers: tensorized $L^2$ projections,\\ $\mathcal O(p^{d+1})$
                \item Level operators: sum-factorized
                \item Smoother:
                      \begin{itemize}
                          \item damped Jacobi
                          \item fast diagonalization of the \emph{reference} patch as preconditioner:\\ the ``Cartesian-reinforced'' smoother
                      \end{itemize}
            \end{itemize}
        \end{column}
        \begin{column}{0.45\textwidth}
            \begin{block}{Coarse solver ($p=1$)}
                One interior node left:
                \begin{gather*}
                    A_{j,1}^{-1} = \frac{1}{A_{j,1}}
                \end{gather*}
                The coarse solve is \alert{a single division}.
            \end{block}
            \vspace{0.5em}
            \begin{itemize}
                \item Memory: $\mathcal O(p^d)$ --- optimal
                \item Work per V-cycle: $\mathcal O(p^{d+1})$,\\ same as \emph{one} operator application (up to a constant)
            \end{itemize}
        \end{column}
    \end{columns}
\end{frame}

\begin{frame}{Rewrite assumptions: what modern hardware wants}
    \textbf{Target: GPUs} (A100: 2\,TB/s DRAM, fp64 tensor cores)
    \vfill
    \begin{block}{The classical pipeline is built around its worst operation}
        \begin{itemize}
            \item gather $\to$ compute $\to$ scatter (atomics!)
            \item Indirect addressing on \emph{every} operator application
            \item Full bandwidth attainable \alert{only} with \emph{coalesced} access
        \end{itemize}
    \end{block}
    \vfill
    \pause
    \begin{block}{My answer: cell-wise vector as persistent storage}
        \begin{itemize}
            \item DG-like storage for CG: DoFs duplicated across interfaces
            \item Every access coalesced --- no atomics
            \item Price: up to $8\times$ memory at $p=1$, shrinking fast with $p$
        \end{itemize}
    \end{block}
\end{frame}

\begin{frame}{The key identity: primal--dual pairing}
    Two kinds of vectors live in the redundant cell-wise space $\mathbb V_{\text{cell}}$:
    \begin{itemize}
        \small
        \item \textbf{Primal} $u$: continuous fields, duplicated entries agree
        \item \textbf{Dual} $\tilde r$: raw unassembled cell integrals (residuals) --- valid \emph{without} summation
    \end{itemize}
    \emph{Constraint:} primal fields satisfy $u = Cu$ for idempotent operator $C$

    \begin{block}{Duality pairing identity}
        \vspace{-1.2em}
        \begin{gather*}
            u = Cu \quad\Longrightarrow\quad
            \langle \tilde r, u \rangle
            = \langle \tilde r, C u \rangle
            = \langle C^T \tilde r, u \rangle
        \end{gather*}
        \vspace{-1.6em}\\
        {\small The \emph{local} pairing of unassembled residuals with a continuous field
        \alert{equals the assembled global pairing.}}
    \end{block}
    \begin{itemize}
        \small

\begin{frame}{Adaptivity: what classical local multigrid needs}
    \small
    Local smoothing\footnote{Janssen and Kanschat (2011).}: level $\ell$ smooths only where level-$\ell$ cells exist;
    cost $\propto$ \#active cells
    \begin{center}
        \resizebox{0.62\textwidth}{!}{\input{figures/fig_mg_levels.tex}}\\
        {\scriptsize Active mesh (left) and its level meshes; refinement edge $E_\ell$ in green}
    \end{center}
    The classical implementation carries:
    \begin{itemize}
        \item hanging-node constraint matrix $C_{HN}$ inside every operator application
        \item split level matrix: smooth with $A^{SS}$, \emph{edge operators} $A^{SE}, A^{ES}$ for the coupling
        \item restriction through the transposed constraints $\mathcal R\, C_{HN}^T$
    \end{itemize}
    $\Rightarrow$ index lists, special cases, branches inside kernels \alert{--- exactly what a GPU hates}
\end{frame}

\begin{frame}{Why hanging nodes are gone}
    \small
    All three pieces turn into identities once vectors are cell-wise and residuals stay unassembled\footnote{Wichrowski
        (2026), Coalesced MG on cell-wise storage.}:
    \vspace{0.1em}
    \begin{enumerate}
        \item \textbf{Prolongation:} \quad $C_{HN}\,\mathcal P = \mathcal P$\\
              a prolongated coarse field is \emph{already} continuous on the refinement edge --- nothing to enforce
              \pause
        \item \textbf{Restriction:} \quad $\mathcal R_{\text{cell}}$ applied to the \emph{unassembled} residual
              $\;=\; \mathcal R\, C_{HN}^T$\\
              plain tensor-product transfer, cell by cell; no constraints
              \pause
        \item \textbf{Edge operators:} \quad a pointwise $0/1$ mask on the smoother
              \begin{itemize}
                  \item full cell operator reads the edge values $u^E$ $\to$ applies $A^{SE}$ on the fly
                  \item mask residual and correction on $E_\ell$ $\to$ relaxation with $A^{SS}$
                  \item unmasked residual after smoothing carries $A^{ES}$ to the coarse level
              \end{itemize}
    \end{enumerate}
    \pause
    \begin{block}{Theorem}
        The cell-wise V-cycle equals classical local multigrid \alert{iterate by iterate}.
    \end{block}
\end{frame}

\begin{frame}{Bonus: the DSS does not need to know either}

            \centering
            \resizebox{\textwidth}{!}{\input{figures/fig_dss_lshaped.tex}}

\end{frame}

\begin{frame}{Same storage, discontinuous Galerkin}
    SIPG on Cartesian cells: DG is cell-wise by nature --- the storage layout is a free tuning parameter
    \vfill
    \begin{block}{Hermite-type 1D basis: all face data in two layers}
        \begin{itemize}
            \small
            \item Endpoint value and derivative \emph{are} coefficients: $u(0)=u_0$, $u'(0)=u_1$
            \item Face trace = DoF layer 0, normal derivative = layer 1
            \item Face coupling collapses to a symmetric $4\times 4$ stencil under $M\otimes M$ --- reads $2(p{+}1)^{d-1}$ values per
                  side instead of $(p{+}1)^d$
        \end{itemize}
    \end{block}
    \vfill
    \begin{block}{Face sweeps without atomics}
        \begin{itemize}
            \small
            \item One sweep per axis, each face evaluated \emph{once}, writing both neighbours
            \item Race-free: lower face writes layers $\{0,1\}$, upper face $\{p{-}1,p\}$
            \item With atomics instead: \alert{$-43\%$} throughput. Without: face kernel at \alert{81\% of peak bandwidth}
        \end{itemize}
    \end{block}
\end{frame}

\begin{frame}{Non-matching faces: shadow cells}
    \begin{columns}[c]
        \begin{column}{0.52\textwidth}
            \centering
            \resizebox{\textwidth}{!}{\input{figures/fig_dg_shadow.tex}}\\[0.3em]
            {\scriptsize gray: shadow children; red: matching fine--shadow faces}
        \end{column}
        \begin{column}{0.46\textwidth}
            \footnotesize
            \begin{itemize}
                \item Coarse cells at a refinement edge are refined \emph{virtually}
                \item \textbf{Shadows} hold the prolonged parent: no own DoFs, no volume integral
                \item Every face has a \alert{same-level partner}: one face kernel, no subface quadrature \pause
                \item \textbf{Exact}, not approximate\footnote{Wichrowski (2026), Adaptive multilevel DG on GPUs.}:
                      \[
                          \mathcal G_{\text{sh}}^T\,\tilde A\,\mathcal G_{\text{sh}} = A
                      \]
                \item Cost: one cell-deep layer, surface-order
            \end{itemize}
        \end{column}
    \end{columns}
\end{frame}

\begin{frame}{Shadows are primal--dual too}
    \begin{columns}[T]
        \begin{column}{0.55\textwidth}
            \small
            Shadows are just another redundant copy:
            \begin{itemize}
                \item \textbf{primal}: shadow $=$ prolongation of its parent
                \item \textbf{dual}: shadow holds fluxes destined for its parent
            \end{itemize}
            Same pairing identity as before:
            \[
                \langle \tilde f, \mathcal G_{\text{sh}} u \rangle = \langle \mathcal G_{\text{sh}}^T \tilde f, u\rangle
            \]
            $\Rightarrow$ CG \alert{never assembles} the shadows
            \vspace{0.6em}

            In the local V-cycle:
            \begin{itemize}
                \item shadows $=$ frozen inter-level Dirichlet data
                \item zero on the way down, filled by prolongation on the way up
                \item shadow assembly fused into the restriction
            \end{itemize}
        \end{column}

\begin{frame}{As promised: the biharmonic problem}

                    \item value + derivative at each end (1D)
                    \item $2^d = 8$ unknowns per vertex, $8$ per cell\\ ($C^0$ Lagrange $\mathbb Q_3$: $27$)

\begin{frame}{Why keep the Cartesian mesh?}
    \begin{columns}[T]
        \begin{column}{0.5\textwidth}
            \small
            Everything so far loves \alert{Cartesian cells}:
            \begin{itemize}

\begin{frame}{CutFEM in one slide}
    \small
    Poisson, Dirichlet data imposed weakly (Nitsche) on the cut boundary $\Gamma$:
    \begin{align*}
        A_\ell(u,v) & = (\nabla u,\nabla v)_\Omega - (\partial_n u, v)_\Gamma - (u,\partial_n v)_\Gamma
        + \tfrac{\gamma_D}{h}(u,v)_\Gamma                                                                    \\
                    & \quad + \underbrace{\gamma\sum_{F\in\mathbb F_G}\sum_{k=1}^{p}\tfrac{h^{2k-1}}{(k!)^2}
            \big(\llbracket\partial_n^k u\rrbracket, \llbracket\partial_n^k v\rrbracket\big)_F}_{\text{ghost penalty}}
    \end{align*}
    Cut cells can be \alert{arbitrarily small}; the \alert{ghost penalty} glues them to their neighbours:
    stability independent of the cut.
    \pause
    \begin{block}{Ghost penalty on Cartesian cells = tensor product\footnote{Wichrowski (2026), Matrix-free ghost penalty
                via tensor-product factorization.}}
        \vspace{-1.2em}
        \begin{gather*}
            g_F(u,v) = v^T \bigl(G \otimes M \otimes M\bigr)\, u
        \end{gather*}
        \vspace{-1.8em}
        \begin{itemize}
            \item $G$: 1D ghost matrix on two cells, $M$: 1D mass matrix
            \item $\mathcal O(p^{d+1})$ like the operator: matrix-free, any order
        \end{itemize}
    \end{block}
\end{frame}

\begin{frame}{What I proven }
    Levels are \emph{non-inherited}: every level has its own active mesh and its own ghost faces;
    energy lives on $\Omega$, functions on $\Omega_\ell \supseteq \Omega$

    \begin{block}{Theorems\footnote{Wichrowski (2026), A multigrid method for CutFEM and its convergence.}}
        \begin{itemize}
            \item Two-level convergence \alert{independent of $h$ and of how $\Gamma$ cuts the mesh}
            \item W-cycle: the same, under a smallness assumption on the two-level rate
            \item Parallel variants covered: damped colouring, stride-$3$ strip colouring
        \end{itemize}
    \end{block}
    \vfill
    \pause
    \begin{block}{The price: the polynomial degree}
        \begin{itemize}
            \item Constants grow like $\exp(2p\log p)$ --- traced to the \alert{ghost-penalty energy}
            \item The loss lives in the \alert{boundary strip}
            \item The ghost penalty is the knob to turn
        \end{itemize}
    \end{block}
\end{frame}

    \begin{itemize}
        \item \textbf{visibility}: a degree-$p$ cut mode sees the penalty only when $\gamma \gtrsim \kappa^{2p-1}$

        \item[$\Rightarrow$] incompatible as $p$ grows; practical choice: \alert{shed the penalty like $p^{-2}$}
    \end{itemize}

\begin{frame}{Finite strain: from an energy straight to CutFEM}
    \small
    \textbf{One} augmented energy\footnote{Wichrowski and Noomen, A unified CutFEM formulation for finite-strain elasticity, \emph{CMAME}, accepted.} (Nitsche weight $\eta(\bar u)$ frozen at the current iterate):
    \begin{align*}
        \mathcal E_{\text{tot}}(u) = {} & \int_\Omega \Psi(F)\,dV - \text{loads}            \\
                                        & \underbrace{-\int_{\Gamma} n\cdot P(u)\cdot u\,dS
            + \int_{\Gamma}\tfrac{\gamma_D\,\eta(\bar u)}{2h}|u|^2 dS}_{\text{Nitsche}}
        + \underbrace{\tfrac{\gamma_A}{2}\sum_{F}g_F(u,u)}_{\text{ghost penalty}}
    \end{align*}
    \vspace{-0.8em}
    \begin{center}
        \begin{tikzpicture}[node distance=0.45cm and 0.7cm,
            box/.style={draw, rounded corners, thick, align=center, inner sep=2pt, font=\footnotesize},
            arr/.style={-{Latex[length=2mm]}, thick}]
            \node[box, fill=orange!20] (psi) {$\Psi(F)$\\ \tiny scalar energy};
            \node[box, fill=blue!10, right=of psi] (ad) {AD\\ \tiny (AceGen)};
            \node[box, right=of ad] (PL) {$P = \dfrac{\partial\Psi}{\partial F}$,\quad
                $\mathbb L = \dfrac{\partial^2\Psi}{\partial F^2}$};
            \node[box, fill=green!15, right=of PL] (res) {residual\\ + tangent};
            \draw[arr] (psi) -- (ad);
            \draw[arr] (ad) -- (PL);
            \draw[arr] (PL) -- (res);
        \end{tikzpicture}
    \end{center}
    \vspace{-0.9em}
    \begin{itemize}
        \footnotesize
        \setlength{\itemsep}{0.15em}
        \item Residual = exact first variation; tangent symmetrised (one $\partial^3\Psi$ term dropped)
              % \item Nitsche weight read off the AD tensor: $\eta = \max\{2\mu,\ \tfrac12\|\mathbb L\|_1\}$
        \item Jacobian defect $=\mathcal O(h^{\,p-d/2})\to 0$: quasi-Newton on a fixed mesh, \alert{asymptotically Newton} under
              refinement ($p>d/2$)
        \item \alert{New material = one new line}
        \item Proven: cut-independent coercivity, $\operatorname{cond} = \mathcal O(h^{-2})$, quasi-optimal error
    \end{itemize}
\end{frame}

\begin{frame}{Going general: takeaways}
    \begin{itemize}
        \item The \alert{Cartesian background} keeps the tensor structure: ghost penalty = 1D matrices, $\mathcal O(p^{d+1})$
        \item Vertex-patch multigrid for CutFEM
              \begin{itemize}
                  \item partial patches at exterior vertices, \alert{full-residual} local spaces
                  \item provably robust in $h$ and in the cut position
                  \item $p$-dependence confined to the boundary strip; shed the ghost penalty $\sim p^{-2}$
              \end{itemize}
        \item \alert{AD $\to$ CutFEM}: write $\Psi$, get a finite-strain unfitted solver
              \begin{itemize}
                  \item any hyperelastic model, same code
                  \item optimal rates, cut-independent conditioning
                  \item \alert{adaptivity is a must}: corner singularities otherwise cap the rates
              \end{itemize}
    \end{itemize}
